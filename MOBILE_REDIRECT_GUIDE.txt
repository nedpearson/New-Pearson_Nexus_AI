🎯 FEATURE: Automatic Mobile Detection & Redirect

When opening the app on a mobile device, it now automatically
redirects to the mobile app interface.

   Desktop Computer:

───────────────────────────────────────────────────────────────────

🔍 DETECTION METHODS:

   Method 1: User Agent Detection
   • Detects: Android, iOS, iPad, etc.
   • Checks: navigator.userAgent
   • Patterns: iPhone, Android, iPod, etc.

   Method 2: Screen Size Detection
   • Detects: Small screens (≤768px)
   • Checks: window.innerWidth
   • Fallback: If user agent fails

⚙️ PREFERENCE SYSTEM:

   Default Behavior:
   • Mobile devices → Mobile interface
   • Desktop devices → Desktop interface

   Override Options:
   1. Tap "Desktop" button in mobile app
      → Saves preference to use desktop
      → Stops auto-redirecting to mobile
      → Preference lasts for session

   2. Add ?desktop=true to URL
      → Forces desktop view
      → Example: http://192.168.0.28:3001/?desktop=true

   Reset Preference:
   • Close all browser tabs
   • Or clear sessionStorage
   • Or tap "Capture" tab in desktop view

💡 TECHNICAL DETAILS:

   Detection Code:
   ```javascript
   const isMobile = /Android|webOS|iPhone|iPad|
     iPod|BlackBerry|IEMobile|Opera Mini/i.test(
       navigator.userAgent
     );
   
   const isSmallScreen = window.innerWidth <= 768;
   
   if (isMobile || isSmallScreen) {
     navigate('/mobile');
   }
   ```

   Preference Storage:
   ```javascript
   // Set desktop preference
   sessionStorage.setItem('prefer_desktop', 'true');
   
   // Check preference
   const preferDesktop = 
     sessionStorage.getItem('prefer_desktop') === 'true';
   ```

   Redirect Logic:
   ```javascript
   // Skip redirect if:
   - Already on /mobile, /m, /mobile-dashboard
   - User set desktop preference
   - URL has ?desktop=true
   - Not a mobile device
   ```
