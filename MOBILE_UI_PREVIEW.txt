## Design Features

### Animated Elements:
1. **Pulsing recording ring**: Indicates active recording
2. **Gradient backgrounds**: Subtle animated gradients
3. **Smooth transitions**: All state changes animated
4. **Button hover effects**: Subtle lift and glow
5. **Spinner animations**: During processing

### Color Palette:
```
Primary Colors:
- Cyan:     #06B6D4 → #0891B2
- Blue:     #2563EB → #1D4ED8
- Purple:   #A855F7 → #9333EA
- Pink:     #EC4899 → #DB2777
- Emerald:  #10B981 → #059669
- Teal:     #14B8A6 → #0D9488

Background:
- Dark:     #020617 (slate-950)
- Mid:      #1E3A8A (blue-950)
- Accent:   #0F172A (slate-900)

Text:
- Primary:  #FFFFFF (white)
- Secondary: #94A3B8 (slate-400)
- Muted:    #64748B (slate-500)

Status:
- Success:  #10B981 (emerald-500)
- Error:    #EF4444 (red-500)
- Info:     #06B6D4 (cyan-500)
```

### Typography:
- Headers: Bold, White
- Body: Regular, Slate-300
- Labels: Medium, Cyan/Purple/Emerald
- Timer: Mono, Bold, White

- Camera open: < 500ms

### Optimizations:
- Lazy loaded images
- Debounced inputs
