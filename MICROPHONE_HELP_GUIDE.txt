🔍 ERROR DETECTION:

   Error Types Handled:
   ┌──────────────────────────────────────┐
   │  NotAllowedError                     │
   │  → Permission denied                 │
   │  → Shows help button                 │
   │                                      │
   │  NotFoundError                       │
   │  → No microphone found               │
   │  → Check device settings             │
   │                                      │
   │  NotReadableError                    │
   │  → Microphone already in use         │
   │  → Close other apps                  │
   └──────────────────────────────────────┘

   Code:
   ```javascript
   catch (error) {
     if (error.name === 'NotAllowedError') {
       setShowMicHelp(true);
       errorMessage = 'Permission denied. Tap for help.';
     } else if (error.name === 'NotFoundError') {
       errorMessage = 'No microphone found.';
     } else if (error.name === 'NotReadableError') {
       errorMessage = 'Microphone in use.';
     }
   }
   ```

💡 TROUBLESHOOTING:

   Still Getting "Denied"?

   iPhone/iPad:
   1. Go to Settings → Safari
   2. Tap "Settings for Websites"
   3. Tap "Microphone"
   4. Make sure it's set to "Allow"
   5. Close all Safari tabs
   6. Reopen the app

   Android:
   1. Go to Settings → Apps → Chrome
   2. Tap Permissions → Microphone
   3. Make sure it's "Allowed"
   4. Clear Chrome cache (optional)
   5. Reopen the app

   Desktop:
   1. Click lock icon in address bar
   2. Click "Site settings"
   3. Find Microphone → Allow
   4. Reload page
