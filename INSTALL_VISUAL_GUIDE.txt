## Week-Long Use Example

```
SUNDAY (At Home):
  📶 On WiFi
  → Install app
  → Test it works
  
MONDAY - FRIDAY (Away):
  📴 No WiFi
  → Open app anywhere
  → Take 15 photos
  → Add voice notes
  → Status: "Offline • 15 pending"
  
FRIDAY NIGHT (Back Home):
  📶 On WiFi
  → Open app
  → Status: "Online • 15 pending"
  → Tap "Sync Now (15)"
  → ✅ All week's data uploaded!
```
