2. Wait 3 seconds

- Must do this **while on home WiFi** first time

## 💾 How Offline Works

### When You Install:
1. **All app files downloaded to phone**
   - HTML, JavaScript, CSS
   - Images, icons, assets
   - Service worker for offline support
   
2. **Stored permanently on device**
   - Takes ~5-10 MB storage
   - Stays until you manually delete
   - Updates automatically when online

### Away From Home:
```
1. Open app from home screen
   ✅ Loads instantly (from phone storage)
   
2. Take photos, record voice notes
   ✅ All saved locally on phone
   
3. Check "Files" tab
   ✅ See all your offline captures
   
4. Shows: "Offline Mode • 5 pending"
   ✅ App tracks what needs to sync
```

### Back Home/Online:
```
1. Connect to WiFi or mobile data
   ✅ Status changes to "Online • 5 pending"
   
2. Tap "Sync Now (5)" button
   ✅ All offline data uploads to server
   
3. Success: "Synced 5 items!"
   ✅ Data backed up to home server
   
4. Continues working normally
   ✅ Auto-syncs every 12 hours when online
```
