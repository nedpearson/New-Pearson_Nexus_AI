# Pearson Nexus AI — Product brief (give this to Bolt)

## One-line purpose
Pearson Nexus AI is a **personal + business organization system** that turns scattered information (documents, bills, tasks, life/business events) into an **easy dashboard**, and helps users take action using **proof-linked, step-by-step workflows**.

## Non-negotiables
- **Simple-first UX**: default to Simple View so non-technical users feel safe.
- **Proof-first outputs**: any recommendation or eligibility statement must include sources + linked documents (“View Proof”).
- **Actionable workflows**: not just summaries—checklists, templates, and submission links where appropriate.
- **User learning loop**: the system improves as users approve/correct categories and outcomes.

## Core screens (Simple View)
- Dashboard (tiles)
- Documents (add, categorize, approve; link as proof)
- Bills (pay links + calendar)
- Tasks
- Calendar
- Recommendations (simple cards)
- Settings (Simple/Advanced toggle)

## Advanced modules (unlocked + Advanced View)
Financial:
- Transactions
- Assets/Liabilities
- Net worth drill-down with proof

Legal (consumer-friendly):
- Personal legal workspace
- Divorce/custody workspace (configurable)
- Case timeline + tasks + evidence packet builder

Business growth:
- Templates library (loans, tax credits, grants)
- Packet builder (prefilled fields + evidence checklist + export)
- Funding Navigator (track opportunities and submissions)

Premium advisory lanes:
- Tax Attorney Mode (structured packet workflow)
- Financial Advisor Mode (savings/strategy playbooks with sources)
- Entity Builder Mode (LLC vs corp + state strategy + decision memo)

Admin (last):
- A full admin console for nedpearson@gmail.com to manage subscribers, plans, usage, and marketing metrics.

## Weekly policy/program updates (later, controlled)
A module that produces weekly “changes that may benefit you” cards.
Must use a review queue and publish only after approval.
