# Feature Catalog (organized)

## MVP (Simple View)
- Dashboard tiles (reorder, hide/show, persist)
- Documents hub (add/upload, categorize, approve, summaries)
- Proof links (documents linked to every output)
- Bills (due dates, pay links, calendar linking)
- Tasks + Calendar
- Basic Recommendations (status: new/viewed/accepted/dismissed)
- Settings (profile + Simple/Advanced toggle)

## Advanced View (post-MVP)
- Transactions
- Assets/Liabilities
- Net Worth drill-down with proof

## Business Growth Lane
- Templates library (loan/grant/tax credit packets)
- Prefill engine (profile + financials + docs)
- Evidence checklists
- Indexed binder exports + versioning
- Funding Navigator pipeline with submission links
- Citations, assumptions, risk flags

## Advisory Lane (premium)
- Tax Attorney workflow UI (intake -> packet -> review -> export)
- Financial Advisor workflow UI (options -> action plan -> templates -> submit)
- Entity Builder (LLC vs corp; state strategy; decision memo)

## Admin Lane (last)
- Subscriber management
- Revenue and analytics dashboard
- Marketing dashboard
- Policy updates review/publish
