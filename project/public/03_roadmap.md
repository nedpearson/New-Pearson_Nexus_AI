# Roadmap (build without overwhelming users)

## Stage 1: “Daily Organizer” (MVP)
Goal: a product you personally use every day.
- Dashboard tiles
- Documents + proof links
- Bills + pay links + calendar linking
- Tasks + Calendar
- Simple Recommendations

## Stage 2: “Business Ready”
- Transactions + net worth
- Legal workspace + evidence packets
- Templates library foundation

## Stage 3: “Get Funding + Credits”
- Funding Navigator pipeline
- Prefilled packets + binder export
- Submission tracking

## Stage 4: “Advisor Lanes”
- Tax Attorney Mode
- Financial Advisor Mode
- Entity Builder Mode

## Stage 5: “Admin + Growth Engine”
- Admin console (subs, revenue, marketing)
- Analytics and campaign tracking
- Policy Updates review + publish
