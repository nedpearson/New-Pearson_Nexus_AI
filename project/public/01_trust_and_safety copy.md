# Trust & safety (non-negotiable product rules)

## Must show
- Sources for policy/program statements (links + citations)
- Assumptions when user data is missing
- Risk flags when eligibility is uncertain

## Must not claim
- “Guaranteed approval” for loans/credits/grants
- “Legal/tax advice” language

## UX labeling
- Educational guidance
- Recommend review by a qualified professional
- Provide a clear “View Proof” path for every claim

## Workflow safety
- Any internet-derived update goes to a Review Queue before being published.
