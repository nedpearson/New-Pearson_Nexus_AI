# Simple View vs Advanced View (UX rule)

## Default: Simple View
Show only what a non-technical user needs daily:
- Dashboard
- Documents
- Bills
- Tasks
- Calendar
- Recommendations (basic)
- Settings

Hide:
- Transactions
- Net Worth
- Funding Navigator
- Templates
- Advisory workflows
- Admin

## Advanced View
Reveal deeper modules ONLY if:
- user toggles Advanced, AND
- feature is unlocked by plan/add-on

## Copy rules
- Replace “transactions” with “activity” where possible.
- Use “proof” as a simple label: “View Proof”.
- Use guided steps; avoid dense tables.
