🔒 PHOTO SECURITY GUARANTEE:

   ✅ ONLY the photo YOU select gets uploaded
   ✅ NO access to your entire photo library
   ✅ NO automatic uploads
   ✅ Manual "Save Evidence" tap required for EVERY upload
   ✅ Input cleared after each selection (safety measure)

   How It Works:
   1. You tap "Take Photo" or "Upload File"
   2. Browser shows file/camera picker (native OS)
   3. YOU select ONE photo/file
   4. ONLY that ONE file is stored temporarily
   5. Nothing uploads until you tap "Save Evidence"

   Technical: Uses HTML5 File API (standard browser security)
   - Sandboxed file access
   - One file at a time
   - Explicit user interaction required
   - No background access

🔐 SECURITY FEATURES:

   File Input Security:
   ┌────────────────────────────────────────────────────┐
   │  <input                                            │
   │    type="file"                                     │
   │    accept="image/*"        ← Only images shown     │
   │    capture="environment"   ← Rear camera           │
   │    onChange={(e) => {                              │
   │      // ONLY handle the single selected file      │
   │      const file = e.target.files?.[0] ?? null;    │
   │      handleCameraCapture(file);                    │
   │      e.target.value = '';  ← Clear for safety     │
   │    }}                                              │
   │  />                                                │
   └────────────────────────────────────────────────────┘

   Upload Handler:
   ┌────────────────────────────────────────────────────┐
   │  const handleCameraCapture = (file: File | null) {│
   │    if (!file) return;                              │
   │    // IMPORTANT: Only store the explicitly         │
   │    // selected file - no library access           │
   │    setSelectedFile(file);                          │
   │    setStatus({ type: 'success', ... });          │
   │  };                                                │
   └────────────────────────────────────────────────────┘
